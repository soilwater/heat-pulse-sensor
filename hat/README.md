# Compact Nano R4 heat-pulse hat

Current design: **HP-HAT**, four layers, 0.8 mm thick. The 43.18 × 17.78 mm body is exactly the Arduino Nano R4 outline and pin layout, with parts on both faces.

- [Assembly dimensions, selected headers and drawing](mechanical/ASSEMBLY.md)
- [Design, operation and manufacturing files](fab/README_HAT.md)
- [JLCPCB order settings](fab/ORDER_SETTINGS.md)
- [Release checks and file hashes](fab/RELEASE_MANIFEST.txt)

The `flat-nano` version is the reference for the needles and shared parts; its files are only read. The Nano and hat are soldered face inward with a 4.00 mm gap. The potted body target is 10.5 mm thick, which the nominal 10.49 mm stack meets only with the full 1 mm cover per face; verify the fit on the first assembly.
